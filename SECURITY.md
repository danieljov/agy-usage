# Security Policy

## Supported Versions

Security fixes are applied to the latest published release on [crates.io](https://crates.io/crates/agy-usage) and [GitHub Releases](https://github.com/danieljov/agy-usage/releases/latest).

| Version | Supported |
| :--- | :---: |
| Latest release | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report vulnerabilities privately using [GitHub Private Vulnerability Reporting](https://github.com/danieljov/agy-usage/security/advisories/new).

When submitting a report, please include:
- The version of `agy-usage` (`agy-usage --version`) and operating system.
- Steps or inputs required to reproduce the issue.
- The potential impact of the vulnerability.

You can expect an initial acknowledgment within 7 days and a coordinated fix or mitigation plan once the issue is verified.
